HOW TO PUBLISH
--------------
1. Back up your existing local kastanie-website folder.
2. Copy the CONTENTS of this folder over the existing website repository
   contents (index.html, en.html, assets/, img/, privacy pages, etc.).
3. Commit and push to GitHub Pages. This archive does not publish anything.
4. Check https://kastanie.wien/ and https://kastanie.wien/en.html on a phone
   and a desktop browser.
5. Click the free-photo button and confirm the contact panel opens.
6. Submit a TEST registration in each Zoho form, then check that it appears
   in Zoho Forms Entries. Remove your test entries afterward.

BEFORE PROMOTING THE PAID SERVICE
---------------------------------
- Do not offer bookings, prices, signed partners or guaranteed availability
  before those commitments are genuinely in place.
- In Zoho, confirm the optional question about interest type and the
  OPTIONAL number-of-houseplants question (including 'Noch keine' / 'None yet')
  are included in BOTH language forms if you want your planned demand study.
- Review Zoho's embed settings and privacy/consent wording. Zoho owns form
  fields, storage and notification settings — these cannot be changed from
  the static website files.
- Service photos are illustrative generated imagery, not photos of actual
  Kastanie customer visits or partner nurseries.
- Check the Firmenbuch (FN) information in the Impressum and update it with
  the actual number once available.
