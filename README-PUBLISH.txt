KASTANIE — FINAL WEBSITE PACKAGE (18 October 2026)

This package contains the German and English landing pages, optimized 3D images,
photo-contact dialog, and embedded German/English Zoho waiting-list forms.

IMPORTANT: The red Adobe Acrobat floating button visible on some Chrome browsers
is added by the visitor's Adobe Acrobat browser extension. It is not present in
these website files and cannot be removed for visitors through the site itself.
To hide it in your own browser: Chrome > Extensions > Manage Extensions >
Adobe Acrobat > disable the extension, or restrict its site access.

PUBLISHING (for the existing GitHub Pages repository):
1. Back up your local project folder.
2. Extract this ZIP.
3. Copy the CONTENTS of the 'kastanie-website' folder into the root of your
   local website project/repository, preserving 'img/' and 'assets/' folders.
   Do not put the folder itself inside the current project folder.
4. Review the German index.html and English en.html in a browser.
5. Confirm the two waitlist forms, language switch, photo contact panel,
   and the Impressum/privacy links all work.
6. Commit and push the updated files to the GitHub repository that publishes
   kastanie.wien. GitHub Pages deploys according to your repository settings.
7. After deployment, force refresh with Ctrl+Shift+R and test on mobile.
